# Vadão Links

Página de links em um único arquivo (`index.html`), pronta para o GitHub Pages.

## Publicar
Settings > Pages > Deploy from a branch > `main` / `(root)`.

## Editar
- Links: procure por `href="https://` no `index.html`.
- Media kit: troque o `href="#"` do bloco "Media kit" pelo link do Drive (com acesso por link liberado).
